# JavaHelloWorld

A Hello World Java project created with the Visual Studio Code Java project template. The source is in `HelloWorld/src/App.java`.

## Tech stack

- Java
- Visual Studio Code (Java Extension Pack)

## How to run

Open the `HelloWorld` folder in VS Code and run `App.java`, or from the command line:

```bash
cd HelloWorld/src
javac App.java
java App
```
